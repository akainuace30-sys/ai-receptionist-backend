# AI Receptionist Backend

## Purpose
A modular, AI-powered intake platform for law firms that automates client intake across voice and chat, captures structured case data, and drives profitable, recurring revenue.

## Quick Overview
- Multi-channel intake (voice, web chat, WhatsApp, SMS) with consistent data capture.
- Magic-Link 2.0 for evidence upload and dynamic, case-specific forms.
- Lead scoring to prioritize high-value matters before routing to attorneys.
- CRM/calendar integrations (Clio, Lawmatics, HubSpot; Cal.com/Calendly) plus automated follow-ups.
- Security and compliance baked in: encryption, consent logging, and auditability.
